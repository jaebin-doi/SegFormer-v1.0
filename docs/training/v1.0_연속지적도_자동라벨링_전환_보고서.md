## 1. 사용 데이터 / 방식 (★ 정확 명세)

### 1.1 사용 데이터셋

| 항목 | 값 |
|---|---|
| 데이터 | 농림축산식품부 팜맵 (Farm Map) SHP |
| 위치 | `data/labels/farmmap/FARM_*.{shp,dbf,shx,prj}` (9 SHP, 합계 약 6.6 GB) |
| 형식 | ESRI Shapefile (.shp/.dbf/.shx/.prj 4종 세트) |
| 좌표계 | **EPSG:5179** (Korea 2000 통합원점) |
| DBF 인코딩 | **cp949** |
| 분할 단위 | 전국 9 (FARM_1 ~ FARM_9), 경주 영역 = FARM_2 + FARM_3 자동 매칭 |

**핵심 컬럼**:
| 컬럼 | 의미 | 사용 |
|---|---|---|
| `INTPR_CD` | 판독 분류 코드 (01/02/03/04) | ✅ class 매핑 |
| `INTPR_NM` | 판독 분류 한글명 | ✅ 텍스트 라벨 (옵션 C) |
| `PNU_LNM_CD` | 필지 고유번호 (PNU 19자리) | ✅ |
| `LGL_EMD_NM` | 법정읍면동 한글명 | ✅ |
| `LNM` | 지번 | ✅ |
| `AREA` | 면적 (㎡) | 통계 |
| `FMAP_INNB` / `VDPT_YR` / `CHG_CFCD/NM` 등 | 메타 | (보존만) |

### 1.2 INTPR_CD 클래스 매핑

| INTPR_CD | INTPR_NM | class_code | class_name |
|---|---|---|---|
| 01 | 논 | 0 | rice_paddy |
| 02 | 밭 | 1 | dry_field |
| 03 | 과수 | 2 | orchard |
| 04 | 시설 | 3 | greenhouse |
| 그 외 | — | — | 자동 skip (whitelist 정책) |

### 1.3 처리 방식 (코드 흐름)

```
1) discover_farmmap_shps(data/labels/farmmap/) → 9 SHP 정렬 리스트
2) for each GeoTIFF:
   a) rasterio.open(tif).bounds (EPSG:5186)
   b) bbox EPSG:5186 → EPSG:5179 (pyproj.Transformer)
   c) for each FARM_*.shp:
        pyogrio.read_dataframe(shp, bbox=bbox_5179, encoding="cp949")
        → SHP 인덱스 spatial filter (FARM_2/3 외에는 0건, 매우 빠름)
   d) for each polygon:
        - INTPR_CD ∈ {01,02,03,04} whitelist 필터
        - polygon EPSG:5179 → EPSG:5186 reproject (shapely.ops.transform)
        - GeoTIFF alpha 채널 valid_region 과 intersection clip
   e) 옵션별 출력 (PNG / mask GeoTIFF)
```

**API 호출 ❌** — 모든 처리 오프라인 (다운로드 SHP 직접 읽기).

## 3. 4 옵션 사양

### 3.1 색상 팔레트 (대표님 지정)

- 🟢 **논** rice_paddy = `#22C55E` (green-500)
- 🟧 **밭** dry_field = `#F97316` (orange-500)
- 🟥 **과수** orchard = `#EF4444` (red-500)
- 🟦 **시설** greenhouse = `#3B82F6` (blue-500)

### 3.2 옵션 A — 팜맵 단독 2-class (논/밭, PNG only)

- 폴더: `data/labels/팜맵_논밭만/`
- 출력: PNG 6장 (long edge 4096 다운샘플 + 범례)
- 클래스: 논/밭 (`FARMMAP_CLASS_MAP_2`)
- 사용처: 검수 단순화, 학습 외 빠른 확인

### 3.3 옵션 B — 팜맵 단독 4-class (논/밭/과수/시설, PNG only)

- 폴더: `data/labels/팜맵_논밭과수시설/`
- 출력: PNG 6장 (4-class 색상)
- 사용처: 전체 클래스 시각 검수

### 3.4 옵션 C — 팜맵 4-class + 지적정보 텍스트 라벨 (PNG only)

- 폴더: `data/labels/팜맵_논밭과수시설_지적정보/`
- 출력: PNG 6장 + 폴리곤 위 검은 박스 + 흰 글씨로 `"{읍면동} {지번} | {농지분류}"` (예: `"보문동 922-9 | 논"`)
- 폰트: malgun.ttf 16pt (한글 자동 로드)
- 외접 사각형 60px 미만 폴리곤은 가독성 위해 라벨 생략

### 3.5 옵션 D — AI 학습용 mask GeoTIFF (PNG ❌, mask GeoTIFF only)

| 속성 | 값 |
|---|---|
| 폴더 | `data/labels/팜맵_논밭과수시설_AI학습용/` |
| 픽셀 값 | 0=논 / 1=밭 / 2=과수 / 3=시설 / 255=ignore |
| dtype | uint8, 단일 밴드 |
| size | **원본 정사영상과 동일** (다운샘플 ❌) |
| CRS | EPSG:5186 (원본과 동일) |
| transform | 원본과 동일 (1:1 픽셀 매핑) |
| 압축 | LZW |
| nodata | 255 |
| 합계 | 6 mask GeoTIFF / 6.6 MB |

mmsegmentation `LoadAnnotations` 가 그대로 읽음 (ignore_index=255 기본).
