# v1.0 농지 SegFormer 학습 설계 (v2 — 4-class 팜맵 자동 라벨)

> **작성일**: 2026-04-30
> **전제**: `report/2026-04-30/v1.0_연속지적도_자동라벨링_전환_보고서.md` v8 (팜맵 SHP 자동 라벨링 완료, 옵션 D 정본).
> **목적**: 옵션 D 산출물 (mask GeoTIFF 6장) 을 입력으로 4-class 의미 분할 모델 학습.
> **이전 설계 폐기**: `docs/training/농지_SegFormer_학습_설계.md` (9-class + 사람 라벨링) 참고만.

---

## 1. 학습 정책 요약

| 항목 | 값 | 근거 |
|---|---|---|
| 모델 | SegFormer-B2 (MiT-B2 백본, timm Apache-2.0) | 의미 분할 표준, 16GB VRAM 적합 |
| 클래스 | 4: 논(0)/밭(1)/과수(2)/시설(3), ignore=255 | 팜맵 INTPR_CD 직접 매핑 |
| 입력 사이즈 | 학습 = 512×512 RandomCrop, 추론 = 2048×2048 sliding window | mmsegmentation 표준 |
| 데이터 분할 | region 단위 train 4 / val 1 / test 1 | 6 GeoTIFF 기준, split_dataset.py 정책 |
| 손실 함수 | Focal Loss (γ=2) + DiceLoss (0.7:0.3) + class_weight 반비례 | 클래스 불균형 대응 |
| 데이터셋 반복 | RepeatDataset times=4 | 데이터 양 적은 v1.0 보강 |
| Augmentation | RandomResize(0.5~2x) + RandomCrop + Flip H+V + 약한 PhotoMetricDistortion | 농지 도메인 |
| Optimizer | AdamW lr 6e-5, weight_decay 0.01 | SegFormer 논문 표준 |
| Scheduler | LinearLR warmup 1.5k + PolyLR | mmseg 표준 |
| max_iter | 80000 (v1.0 보수적) | 데이터 양 / 조기 saturate 가능 |
| AMP | bf16 (RTX 5080 Blackwell) | VRAM 절감 + 속도 |
| Best 체크포인트 | save_best=mIoU rule=greater | 자동 best 보존 |

## 2. 데이터 파이프라인 (4 단계)

```
[1] 옵션 D mask GeoTIFF (6장, 원본 size, EPSG:5186, uint8 0/1/2/3/255)
       │
       │ src/preprocessing/tiling.py — 영상 + mask 동시 자르기
       ▼
[2] 타일 PNG (2048×2048, overlap 512) + mask PNG (단일 밴드)
       │
       │ --skip-empty-mask-ratio 0.8 — ignore 80% 이상 타일 자동 skip
       ▼
[3] src/preprocessing/split_dataset.py — region 단위 train/val/test (4/1/1)
       │
       ▼
[4] data/dataset/farmland-5cm-v2/{images,masks}/{train,val,test}/*.png
```

### 2.1 타일링 패치 핵심 (tiling.py)

신규 옵션:
- `--mask-input <폴더>` — mask GeoTIFF 동시 처리 (영상 stem 매칭 자동)
- `--skip-empty-mask-ratio 0.8` — mask 의 ignore 비율 80% 이상 타일 자동 skip
- 출력 구조: `images/{stem}/` + `masks/{stem}/` (별도 폴더)

mask 가 영상과 같은 transform/CRS/size 라고 가정 (옵션 D 가 보장).

### 2.2 Split 정책 (변경 없음 — 기존 split_dataset.py 활용)

n=6 GeoTIFF → train 4 / val 1 / test 1 (기존 표 정책).

## 3. 클래스 불균형 대응 (3 단)

### 3.1 라벨 픽셀 분포 (옵션 D mask 통계)

| 클래스 | 픽셀 수 | 라벨 중 비율 | class_weight (반비례) |
|---|---:|---:|---:|
| 논 (0) | 1.77억 | 84.0% | **1.00** |
| 밭 (1) | 0.34억 | 16.1% | **5.21** |
| 과수 (2) | 0.04억 | 1.8% | **23.0** |
| 시설 (3) | 0.16억 | 7.5% | **11.2** |

### 3.2 대응 3 단

1. **Focal Loss (γ=2, α=0.25)** — easy sample (논) loss 자동 감소, hard sample 가중
2. **class_weight 반비례** (`CLASS_WEIGHTS = [1.0, 5.21, 23.0, 11.2]`) — Focal Loss 에 주입
3. **RepeatDataset times=4** — 같은 train 영역을 4배 반복 → RandomCrop 으로 minority class 영역 재추출 확률 증가

### 3.3 Augmentation 정책

```python
RandomResize(scale=2048, ratio_range=(0.5, 2.0), keep_ratio=True)
RandomCrop(crop_size=512, cat_max_ratio=0.75)  # 한 클래스만 75% 이상 차지하는 crop 회피
RandomFlip H + V (각 prob=0.5)
PhotoMetricDistortion(brightness=±16, contrast=0.9~1.1, saturation=0.9~1.1, hue=±5)
```

농지 도메인 특성상 **강한 hue 왜곡 금지** (계절별 색조가 의미를 가짐).

## 4. KPI (v2)

### 4.1 게이트 (필수, 미달 시 verdict.passed=False)

| 지표 | 게이트 | 근거 |
|---|---:|---|
| mIoU 전체 | ≥ 0.55 | 4-class 평균 |
| 논 IoU | ≥ 0.75 | 표본 풍부, 가장 쉬움 |
| 밭 IoU | ≥ 0.55 | 논과 헷갈림 가능 |
| 과수 IoU | ≥ 0.30 | 표본 매우 적음 (2%) — 보수적 |
| 시설 IoU | ≥ 0.65 | 비닐하우스 패턴 명확 |
| 추론 시간 | ≤ 1500 ms / 2048 타일 (RTX 5080) | TTA 끄고 측정 |

### 4.2 목표 (warnings, 통과는 가능)

| 지표 | 목표 |
|---:|---:|
| mIoU 전체 | 0.65+ |
| 논 IoU | 0.85+ |
| 밭 IoU | 0.70+ |
| 과수 IoU | 0.50+ |
| 시설 IoU | 0.80+ |
| 추론 시간 | 800 ms |

### 4.3 KPI 미달 시 대응 플레이북

| 미달 항목 | 대응 |
|---|---|
| mIoU < 0.55 | 데이터 추가 (평택 1 + 다른 지역) + max_iter 80k → 160k |
| 과수 IoU < 0.30 | v1.0 = 3-class (논/밭/시설) 폴백, 과수 v1.1 |
| 시설 IoU < 0.65 | CopyPaste augmentation (시설 patch 다른 위치 합성) + 추가 라벨 |
| 추론 > 1500ms | crop 512→448 또는 batch 6 + 백본 B2 → B0 |
| GPU OOM | crop 512→448 / batch 8→6 / num_workers 4→2 |

## 5. 실행 순서 (5 단계)

```bash
# [1] 의존성 + 학습 데이터 준비 (옵션 D mask GeoTIFF 사전 필요)
bash scripts/labeling/install_deps.sh
OPTION=D bash scripts/labeling/run_four_options.sh

# [2] 학습 의존성 설치 (mmsegmentation, mmengine, mmcv, timm, mlflow)
# 워크스테이션 conda env 에서:
conda activate segformer_farmland
pip install -U "openmim>=0.3.0"
mim install "mmengine>=0.10.0" "mmcv>=2.1.0" "mmsegmentation>=1.2.0"
pip install timm mlflow

# [3] 데이터셋 빌드 (타일링 + split, 합계 ~10분)
bash scripts/training/build_dataset.sh

# [4] 학습 (RTX 5080, 80k iter, ~4시간 추정)
bash scripts/training/train_segformer_farmland.sh

# [5] 평가 + KPI 게이트
bash scripts/training/eval_segformer_farmland.sh
```

## 9. 위험 요소

| 위험 | 진단 | 사전 완화 |
|---|---|---|
| 데이터 양 적음 (6 영상) | mIoU saturate 빠름, 일반화 약 | RepeatDataset + 강한 augmentation |
| 라벨 alignment 오차 1~3m | 외곽 IoU 손실 | (옵션) mask boundary 1px erosion → 외곽 ignore |
| ignore 70.8% — 학습 신호 약 | RandomCrop 시 ignore 만 잡힐 수 있음 | `cat_max_ratio=0.75` + `--skip-empty-mask-ratio 0.8` |
| 과수 표본 0.04억 | 클래스별 IoU 극저 위험 | Focal Loss + class_weight 23x + KPI 게이트 보수적 0.30 |
